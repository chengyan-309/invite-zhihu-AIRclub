# 知乎 AI Researcher Club 邀约 Skill

给 agent 一个个人或 Lab 的主页链接，让它核实研究信息，按固定模板生成可复制的中文邀约。适合负责研究者、实验室邀约的同事使用。

## 第一次使用：先让 agent 读取规则

把下面这段话复制给你的 agent：

```text
请读取并遵循以下 Skill 的完整内容，包括个人和 Lab 两套模板：
https://github.com/chengyan-309/invite-zhihu-AIRclub/blob/main/SKILL.md

在当前对话中，当我发送“邀约AIR＋主页链接”时，请按其中规则执行。AIR 不区分大小写。只生成邀约稿，不代我发送。
如果你无法读取这个文件，请明确告诉我，不要凭猜测执行。
```

如果 agent 打不开 GitHub，打开本仓库的 [SKILL.md](./SKILL.md)，下载文件作为附件发给它，或复制全文到对话里，并要求它遵循。

**新开对话或换一个 agent 时，重新提供 Skill。** 单独发送“邀约AIR”不会让一个没有读过规则的 agent 自动理解任务。若所用工具支持安装自定义 Skill，也可以按该工具的安装方式导入本文件；本仓库无需运行程序。

## 日常使用：发送指令和主页链接

将下面的占位内容换成目标的真实主页链接：

```text
邀约AIR：这里粘贴个人或 Lab 的主页链接
```

`邀约AIR`、`邀约air`、`邀约Air` 都可以。支持个人学术主页、实验室官网、小红书等社交账号主页；优先提供信息完整的官方主页。

一次邀约多人或多个 Lab 时，可以发送多个链接，agent 会分别核验并分别输出文案。

## Agent 会做什么

1. 判断对象是个人 researcher，还是 Lab / 研究团队，选用对应模板。
2. 核验三部分：**人名或 Lab 名称、具体研究方向、代表论文 / 项目 / 开源系统及其作用**。
3. 根据官方主页、论文原文、官方项目页或代码仓库交叉核对，只填模板中的对应位置，其余话术保持原样。
4. 输出完整邀约稿，并在正文之外提供简短核验说明和来源。

不会根据拼音猜中文名，不会把转载当作团队成果，也不会把在研目标写成已实现的能力。信息不足时，会说明缺什么并请你补充。

## 你会收到什么

- **一个 Markdown 代码块**：包含完整邀约，点击代码块的复制按钮即可复制。
- **代码块外的核验说明**：便于检查姓名、方向和成果依据，不需要复制进邀约。
- “完整方案在这里”后保留完整网址，不使用隐藏网址的链接标签。

个人版使用“Hi XX 老师，你好”及个人模板；Lab 版包含邀约标题、两种参与方式和线下活动段落。两套完整模板均在 [SKILL.md](./SKILL.md) 中。

## 遇到问题怎么办

| 情况 | 处理方式 |
| --- | --- |
| 主页需要登录或无法打开 | 提供主页文字、截图或可访问的官方链接。 |
| Agent 没有联网能力 | 提供官方研究介绍、论文摘要或项目资料；证据不足时不能要求它猜填。 |
| 名称、研究方向或成果归属不确定 | 先补充资料，核实后再生成可发送的成稿。 |
| 文案被自由改写，或没有使用代码块 | 提醒 agent 重新读取 SKILL.md，只填规定空位，并将完整稿放在一个 Markdown 代码块内。 |

这份 Skill 负责核验和拟稿，不会自动发送私信、邮件或评论。发送前请结合核验来源做最后检查；规则不能代替事实证据，也不代表模型不会出错。
